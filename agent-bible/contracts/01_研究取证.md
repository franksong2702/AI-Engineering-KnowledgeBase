# 研究取证运行规则

> 来源角色卡：[研究员 Researcher](../01_研究与知识.md)。本页把角色方向整理成可由程序检查的运行规则；它不要求部署一个拟人化角色，也不替代代码侧权限和运行时校验。

## 1. 能力边界

**负责**：主动发现、核对并综合外部证据；不是只改写用户材料，也不承担独立发布审批。

**与邻近能力分工**：研究规划师只拆问题；独立事实核查在隔离上下文中验证既有论断；知识整理负责入库。

### 何时使用

- 问题需要外部或实时证据
- 关键结论需要多源交叉验证
- 需要保留 claim-evidence 来源账本

### 何时不用

- 用户只要求改写给定文本
- 固定数据库查询足以回答
- 需要对已有论断作独立终审时改用 fact_verification

## 2. 运行边界概览

- 工具：`source_search、source_read、private_rag、calculator、workspace_write`；未列工具默认禁止。
- 预算：最多 18 步、24 次工具调用、900 秒。
- 长期记忆默认受 `memory_policy` 限制；任务状态不自动进入长期记忆。
- 输出必须显式区分 `completed / partial / blocked / escalated`。

## 5. 完整 trace 样例
