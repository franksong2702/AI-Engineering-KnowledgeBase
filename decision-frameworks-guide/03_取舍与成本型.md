# 家族三 取舍与成本型：值不值得

> 每个"做"都是对其他选项的"不做"。这一家族处理决策的经济学本质：真实成本、期望回报、以及那些人脑系统性算错的账。

> 关联 Laws：[[laws-of-ai-engineering/06_经济与资源定律#Law 51 — 机会成本定律（Opportunity-Cost Law）|Law 51：机会成本定律]]是本章底层账本，[[laws-of-ai-engineering/06_经济与资源定律#Law 52 — 边际定律（Marginal Law）|Law 52：边际定律]]约束继续投入是否值得，[[laws-of-ai-engineering/06_经济与资源定律#Law 56 — 成本结构决定架构定律（Cost-Structure-Shapes-Architecture Law）|Law 56：成本结构决定架构定律]]解释为什么成本会反过来塑造技术方案。

## 1. 机会成本 Opportunity Cost

**核心思想**：做一件事的真实成本，不是它花掉的钱和时间，而是**被放弃的最优替代选项的价值**。你花一个周末做 A，成本是"这个周末本可以做的最有价值的 B"。经济学最基本也最反直觉的概念之一。

**什么时候使用**：任何资源（时间、钱、注意力、人力）的分配决策；感觉"这个免费/顺手就做了"时（免费的东西也有机会成本）；评估一个看似划算的选项时（它挤掉了什么？）；默认选项"什么都不做"的评估（不做也有机会成本）。

**什么时候不要使用**：陷入无限比较导致行动瘫痪时（每个选择都纠结放弃了什么会寸步难行）；替代选项其实差不多、比较收益低于比较成本时；纯粹的沉浸/享受活动（把休息也算机会成本会毁掉生活）。

**优点**：揭示隐性成本，纠正"这个不花钱所以没成本"的错觉；把决策从"这个好不好"升级为"这个是不是最好的用法"；对时间管理尤其锋利。

**缺点**：替代选项的价值往往难以估计；过度应用导致选择焦虑；容易陷入"总有更好的选择"的完美主义陷阱；心理上令人不适（总在想放弃了什么）。

**AI 如何使用**：做决策时让 AI 主动列出"选这个，你实际上放弃了什么"。人做决策时聚焦于选中的选项，AI 可以强制把被放弃的替代选项摆到台面上，尤其是那个隐形的"什么都不做/维持现状"选项。

**Agent 如何使用**：资源调度型 Agent（预算分配、算力分配、时间规划）的核心逻辑——每次分配决策都显式计算"这笔资源的次优用途回报"作为基准线，只有超过机会成本才执行。

**Prompt 模板**：
```
我在考虑：[某个决策/投入]。它需要[时间/钱/资源]。
请做机会成本分析：
1. 这笔资源的 3 个最有价值的替代用途分别是什么？各自的预期回报？
2. 我正在考虑的选项，回报是否明显高于最优替代？
3. 特别评估"什么都不做/维持现状"这个选项的价值——它常被忽略
4. 有没有隐性成本我没算进去（挤占的注意力、关闭的未来选项）？
不要只评价这个选项好不好，要评价它是不是这笔资源的最佳用法。
```

**完整案例**：一位创业者纠结要不要花三个月自建一套内部 CRM（"反正我们有工程师，不额外花钱"）。机会成本分析戳破"不花钱"错觉：这三个月工程师的最优替代用途是开发付费功能（预期带来可观新增收入）。自建 CRM 省下的订阅费远低于放弃的收入。结论：买现成 CRM，工程师做付费功能。机会成本在这里把"顺手自己做省钱"的直觉，还原成了"你用高价值人力做了低价值的事"的真相。

## 2. 期望值 Expected Value

**核心思想**：一个不确定选项的价值 = Σ（每个结果的价值 × 其发生概率）。用概率加权衡量赌局，而非只看最好或最坏情况。理性决策在重复博弈中应最大化期望值。

**什么时候使用**：结果不确定、但概率和收益可估计的决策；对比几个风险-回报结构不同的选项；对抗"怕万一"（过度权重小概率坏结果）或"搏一把"（过度权重小概率好结果）的情绪；可重复的、单次影响有限的决策。

**什么时候不要使用**：**单次、不可逆、失败会让你出局的决策**（期望值为正但有 5% 破产概率的赌局，长期算法再漂亮你也活不到长期——见下方"遍历性"）；概率纯属捏造时（伪精确比模糊更危险）；收益无法通约（拿健康和金钱做期望值加权在伦理和实践上都可疑）。

**优点**：把模糊的"风险感觉"变成可比较的数字；显式处理概率，对抗直觉对小概率事件的系统性误判；重复决策场景下逼近最优。

**缺点**：依赖概率和收益的估计，垃圾进垃圾出；掩盖方差（两个期望值相同的选项，波动性可能天差地别）；不适用于会致命的单次决策；心理上人对损失的厌恶是收益快感的两倍，纯期望值忽略了这个真实的效用扭曲。

**AI 如何使用**：让 AI 帮你搭期望值模型——列出结果、估概率、算加权，并做敏感性分析（"概率估计变化多少会翻转结论"）。AI 擅长结构化这个计算，但概率来源必须诚实标注是数据还是猜测。

**Agent 如何使用**：决策型 Agent 在多个不确定行动方案间选择时的评分基础，但必须叠加"破产约束"——期望值最高但存在灾难性失败可能的方案要被否决或强制人工确认（把遍历性作为硬护栏）。

**Prompt 模板**：
```
帮我用期望值分析这个决策：[决策 + 可能的结果]
1. 列出所有主要结果、每个的价值、和你估的概率（标注：概率来自数据还是估计）
2. 计算每个选项的期望值
3. 做敏感性分析：哪个概率/收益估计变化会翻转结论？
4. 关键安全检查：有没有哪个选项包含"失败即出局"的灾难性结果？如果有,
   期望值不再适用,请单独警示——不能用长期平均逻辑赌上无法承受的单次损失
5. 同期望值下，各选项的方差（波动）如何？我能承受最坏情况吗？
```

**完整案例**：考虑一个新业务，情形 A：70% 概率赚 100 万，30% 概率亏 50 万 → EV = 70−15 = +55 万，正期望。但安全检查暴露关键问题：那 30% 的"亏 50 万"是否会让公司现金流断裂出局？若会，则无论期望值多正都不能赌——这正是期望值的边界。若 50 万亏损公司扛得住（只是难受不致命），则正期望值 + 可重复性使它值得做。期望值给了量化基准，但"会不会出局"这道遍历性检查才是最终否决权。

## 3. 成本效益分析 Cost-Benefit Analysis

**核心思想**：系统列出一个决策的全部成本和全部收益（尽量货币化或同一量纲），比较总量决定是否值得、以及多个选项中哪个净收益最高。比期望值更全面（含确定性的多项成本收益），比机会成本更系统。

**什么时候使用**：中大型决策需要系统权衡时（采购、投资、项目立项）；成本和收益都相对可估计、可量化时；需要向他人论证决策合理性时；对比多个方案的净收益。

**什么时候不要使用**：重要的成本/收益无法量化时（强行给"员工士气""品牌信任"标价会扭曲结论）；小决策（分析成本超过决策价值）；不确定性极高、估计全靠猜时；用它掩盖价值判断（把伦理问题伪装成算术题）。

**优点**：系统全面，逼你列出容易忽略的间接成本和长期收益；结果可比较、可沟通；显式化假设便于辩论。

**缺点**：难量化项要么被忽略要么被瞎标价，两者都扭曲结论；对未来成本收益的折现和预测充满主观；容易被立场预设操纵（想通过就高估收益低估成本）；给人虚假的客观感。

**AI 如何使用**：让 AI 生成尽可能完整的成本-收益清单，重点是它能提醒你**没想到的间接成本和长期收益**（AI 见过大量类似决策的隐藏项）。量化和权衡仍需人来把关，尤其是那些"AI 给标了价但本质上是价值判断"的项。

**Agent 如何使用**：运营/采购 Agent 在推荐方案时自动生成结构化成本效益表 + 敏感性分析，并明确分区"可量化项"与"需人工判断的软性项"，不把软性项硬塞进算术。

**Prompt 模板**：
```
对决策[方案]做成本效益分析：
1. 列出全部成本：直接的、间接的、机会成本、长期/隐性的（分类列全）
2. 列出全部收益：直接的、间接的、长期的、难量化的
3. 能货币化的货币化并汇总净值；不能货币化的单独列出，不要硬标价
4. 关键：哪些难量化项（如信任、士气、战略选项）可能比数字项更重要？
5. 敏感性：结论对哪个假设最敏感？最乐观和最悲观情形下净收益各是多少？
提醒我：这个决策的核心是算术问题还是价值判断问题？
```

**完整案例**：公司考虑是否上线一个客服 AI 系统。成本效益表——成本：软件年费、集成开发、员工培训、初期错误应答的信任损失（难量化，单列）。收益：人力节省、7×24 响应、响应速度提升带来的满意度（部分难量化）。可量化部分算出净收益为正。但分析把"初期误答的信任损失"和"过度自动化导致复杂问题体验下降"单列为软性风险，提示这不纯是算术题——最终决策叠加了"先小范围灰度、保留人工兜底"的价值判断。成本效益分析的贡献是既给了量化底数，又诚实地把不可量化的战略/信任因素摆出来而非硬塞进数字。

## 4. 沉没成本 Sunk Cost（避免谬误）

**核心思想**：已经付出、无法收回的成本（钱、时间、精力），**不应影响当下的决策**。理性决策只看"从现在往前看的成本和收益"，不看"已经投入了多少"。沉没成本谬误 = 因为"已经投入太多"而继续错误的投入（承诺升级）。

**什么时候使用**：纠结"要不要放弃一个已投入很多但前景黯淡的项目/关系/选择"时；感到"都做到这份上了不能停"时（危险信号）；评估继续 vs 止损的决策；每次"不甘心"的情绪出现时。

**什么时候不要使用**：这不是一个"要不要用"的分析工具，而是一个"始终要警惕"的偏误——它没有"不适用"的场景，只有"别矫枉过正"的提醒：已投入的资源中，有些会产生真实的未来价值（学到的技能、建立的关系），那部分不是沉没成本，别把有价值的积累一起否定了。

**优点**：斩断"承诺升级"这一昂贵陷阱；让决策回归"向前看"的理性基准；心理解放——过去的投入不该绑架未来。

**缺点**：机械应用会显得冷酷、不近人情（人际关系里"都是沉没成本"的算法很伤人）；难以区分"真沉没成本"和"仍在产生价值的投入"；坚持有时是美德（半途而废也是一种病），需要智慧区分"止损"和"逃避困难"。

**AI 如何使用**：当你为"要不要坚持"纠结时，让 AI 帮你把"已投入的"和"未来的成本收益"严格分开——它不带你的情感包袱，能清晰指出"你说的这些理由里，哪些是沉没成本在说话"。

**Agent 如何使用**：长任务 Agent 的止损逻辑——判断是否放弃当前路径时，只评估"从当前状态继续的预期成本收益"，不因"已经跑了很多步"而盲目坚持错误方向（防止 Agent 在死路上越陷越深）。

**Prompt 模板**：
```
我在纠结是否继续[项目/投入/选择]。我已经投入了[已投入的资源]。
请帮我做纯粹的向前看分析：
1. 完全忽略已投入的部分。从今天起，继续 vs 放弃，各自的未来成本和收益是什么？
2. 我列出的"应该继续"的理由里，哪些其实是沉没成本谬误在说话（"都投入这么多了"）？
3. 区分：已投入的资源中，哪些已产生了不可逆转的价值（学到的、建立的）,
   哪些是纯粹沉没、对未来毫无贡献？
4. 抛开不甘心，如果这是别人的项目、我今天才接手，我会选继续还是放弃？
```

**完整案例**：一个人读研三年发现方向没前途，纠结"再熬一年毕业还是转行"。沉没成本视角：三年已无法收回，纠结的核心应是"再投入一年 vs 现在转行"的未来对比。追问发现"不能白读三年"正是沉没成本在作祟。但分析同时区分出：三年里学到的研究方法、建立的人脉是真实资产，不是纯沉没。最终用"如果今天才站在这个路口会怎么选"的换位测试帮他跳出不甘心。注意结论不必然是放弃——若再一年的边际成本低而学位的未来价值高，坚持才是理性；关键是让决策基于向前看的账，而非"都熬这么久了"的情绪。

## 5. 遍历性与凯利准则 Ergodicity & Kelly

**核心思想**：两条紧密相关的洞察。**遍历性**：一群人各玩一次的平均结果，不等于一个人连玩多次的结果——当存在"归零"风险时，个体的长期命运由"会不会破产"决定，而非期望值。**凯利准则**：在可重复的有利赌局中，每次下注的最优比例应使长期增长率最大化，其定性推论是——**永远不下注到会被清零的程度**。核心信念：先保证生存，再优化收益。

**什么时候使用**：涉及反复下注/投入且存在"归零/出局"风险的决策（投资仓位、创业 all-in、健康赌博）；期望值为正但你想知道"该投入多少"时；评估任何"小概率灾难性损失"的选项时；对抗"期望值为正就该干"的天真最大化。

**什么时候不要使用**：真正单次、无重复的决策（凯利是重复博弈的逻辑）；没有归零风险的普通选择（杀鸡用牛刀）；精确套用凯利公式（现实中概率估不准，全凯利波动巨大，实践常用半凯利或更保守）。

**优点**：把"活下去"置于"收益最大化"之上，防御灾难性风险；解释了为什么聪明人也会因为一次 all-in 而破产（他们最大化了期望值却忽略了遍历性）；给出下注规模的理性框架，而不只是方向。

**缺点**：概念反直觉，理解门槛高；精确计算需要可靠的概率（现实常缺）；全凯利的波动性在心理上难以承受；容易被误用为"永远保守"的借口（凯利也惩罚下注不足）。

**AI 如何使用**：让 AI 帮你识别决策中隐藏的"归零风险"——这是期望值分析最容易漏掉的维度。问它"这个选项最坏情况会不会让我出局、无法翻身"，把单次期望值思维升级为生存优先思维。

**Agent 如何使用**：任何涉及资源投注的 Agent（交易、预算、算力分配）的**硬性风控层**：无论期望值多高，禁止任何可能导致"总资源归零/任务不可恢复"的单次投注，把遍历性作为不可逾越的约束而非可优化的目标。(注：金融类操作 Agent 不应自主执行真实交易，只做分析建议。)

**Prompt 模板**：
```
我在考虑[涉及反复投入且有下行风险的决策]。
请用遍历性/生存优先的视角分析：
1. 这个决策是"单次"还是"会反复面临的同类决策"？
2. 最坏情况下，我会不会"归零/出局"——失去继续参与游戏的能力（破产、信誉尽毁、健康崩溃）?
3. 如果存在归零风险：无论期望值多高，都不应下注到这个程度。合理的投入上限是多少？
4. 用凯利的定性逻辑：在保证绝不出局的前提下，什么样的投入规模能让我长期最优？
5. 我是不是在用"平均会赚"的逻辑，赌上了"输一次就完蛋"的本金？
```

**完整案例**：一位投资者发现一个"期望值显著为正"的高杠杆机会，想 all-in。遍历性分析：这是会反复出现的同类决策（他会不断找机会），且高杠杆下单次极端行情可能爆仓归零。关键问题——爆仓一次，他就失去了继续参与的本金和资格，后面再高的期望值都与他无关。凯利逻辑给出的不是"别做"，而是"做，但控制仓位到即使最坏情况也不出局的比例"。他把 all-in 改为小比例下注。一年后果然遇到一次极端行情，重仓者爆仓离场，他因仓位受控活了下来并在后续机会中复利成长。遍历性的核心教益：让你出局的从来不是期望值，而是方差 × 杠杆；先活着，才能享受正期望的长期馈赠。
