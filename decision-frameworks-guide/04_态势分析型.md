# 家族四 态势分析型：看清当前局面

> 决策不在真空里发生。这一家族的框架帮你系统扫描内外部环境，防止"只盯着自己""只看眼前一步"的近视。它们不给行动，给的是行动的地图。

---

## 1. SWOT 分析

**核心思想**：从四个象限系统盘点态势——**Strengths（内部优势）、Weaknesses（内部劣势）、Opportunities（外部机会）、Threats（外部威胁）**。内部（S/W）看自己，外部（O/T）看环境。经典战略盘点工具。真正的价值在第二步：交叉组合（用优势抓机会 SO、用优势御威胁 ST、补劣势抓机会 WO、防劣势遇威胁 WT）生成策略。

**什么时候使用**：战略规划、重大决策前的态势盘点；进入新市场/新项目前的自我评估；需要一个共享的、结构化的"我们现在处于什么位置"的团队认知；个人职业规划。

**什么时候不要使用**：只做四象限罗列而不做交叉推导时（那只是列清单，最常见的滥用）；快速战术决策（太重）；需要量化和优先级时（SWOT 不排序、不量化）；作为决策的唯一依据（它是盘点不是决策）。

**优点**：全面、直观、易上手；同时覆盖内外部、正负面，防止片面；交叉组合能生成具体策略而非泛泛而谈。

**缺点**：极易沦为"四个清单"而无洞察；主观，同一件事可以塞进不同象限；不区分重要性（20 个威胁并列，哪个致命？）；静态快照，忽略动态变化；"优势"是相对竞争对手而言的，脱离对手谈优势没意义。

**AI 如何使用**：让 AI 生成 SWOT 初稿，但强制它做**交叉推导**（SO/ST/WO/WT 策略）而非停在罗列。AI 的另一价值：帮你想到被自己盲区遮蔽的劣势和威胁（人对自己的劣势有系统性盲视）。

**Agent 如何使用**：战略分析 Agent 定期扫描内部数据（能力、资源）和外部信息（市场、竞品、政策，可接搜索/数据工具），自动更新 SWOT 并**高亮变化项**——把静态快照变成动态监测，威胁升级时预警。

**Prompt 模板**：
```
对[主体：公司/产品/我的职业]做 SWOT 分析，背景：[相关信息]
1. 四象限，每项要具体（不要"团队优秀"这种空话，要可验证的具体事实）
2. 优势/劣势必须相对[主要竞争对手/参照系]而言，不能孤立评价
3. 关键：做交叉推导生成策略——
   - SO：如何用优势抓住机会？
   - ST：如何用优势抵御威胁？
   - WO：哪些机会因劣势抓不住，需要先补什么？
   - WT：劣势叠加威胁的最危险组合是什么，如何防？
4. 在所有项里标出最关键的 1 个优势、1 个威胁（不要平均对待）
```

**完整案例**：一个独立开发者用 SWOT 评估要不要全职做自己的 App。S：产品打磨好、有早期口碑、技术全栈。W：无营销经验、资金只够半年、单打独斗。O：该细分市场在增长、大厂尚未进入。T：大厂随时可能进场、获客成本在涨。交叉推导才是关键：WT 组合（缺营销+缺资金 遇上 获客成本涨）暴露了最致命的风险——不是产品不行，是"钱烧完前获不到客"。据此策略调整：不裸辞 all-in，而是先兼职验证获客渠道跑通再全职。SWOT 的贡献是把"要不要辞职"这个情绪化的大问题，分解为"最致命的是 WT 象限的现金流跑道"这个可针对性化解的具体风险。

## 2. PESTEL 分析

**核心思想**：系统扫描影响决策的六类宏观外部因素——**Political（政治）、Economic（经济）、Social（社会）、Technological（技术）、Environmental（环境）、Legal（法律）**。SWOT 的"机会/威胁"往往看得太近，PESTEL 强制你抬头看更大的宏观趋势。

**什么时候使用**：进入新市场、新地区、新行业前的宏观环境扫描；长期战略规划（宏观因素在长周期里起决定作用）；评估外部趋势对业务的影响；识别 SWOT 里容易漏掉的远端威胁和机会。

**什么时候不要使用**：小型、短期、局部的战术决策（宏观因素影响不到）；六个维度里大部分与你的决策无关时（强行填满是浪费）；作为行动方案（它只识别环境因素，不告诉你怎么办）。

**优点**：视野宏大，捕捉容易被忽视的远端力量；六维度结构防止只盯技术或只盯市场；对长期和跨地域决策尤其有价值。

**缺点**：容易变成"宏观趋势罗列"而不落到对你的具体影响；因素太多太远，难判断哪个真正相关；预测宏观趋势本身极不可靠；静态，且难以量化。

**AI 如何使用**：让 AI 扫描六个维度并**筛选出真正影响你决策的少数因素**（配合 80/20）。AI 见多识广，适合快速覆盖六个维度的常见因素，但要求它对每个因素回答"这具体如何、多大程度影响我的决策"，避免泛泛的趋势清单。

**Agent 如何使用**：环境监测 Agent 接入新闻/政策/市场数据源，按 PESTEL 六维持续追踪与你业务相关的宏观信号，出现重大变化（新法规、技术突破、政策转向）时生成影响评估并预警。

**Prompt 模板**：
```
对[决策/业务/进入的市场]做 PESTEL 宏观环境分析：
逐个维度（政治/经济/社会/技术/环境/法律）：
1. 列出与我的决策真正相关的因素（无关的维度直接说"影响有限"，不硬凑）
2. 每个因素：具体如何影响我？是机会还是威胁？时间尺度（已发生/1-3年/更远）？
3. 用 80/20 筛选：这么多因素里，哪 2-3 个最可能实质影响成败？
4. 哪些因素是我完全不可控只能适应的，哪些是我能提前布局的？
```

**完整案例**：一家公司考虑把业务扩展到海外某地区。PESTEL 扫描发现：Political——当地数据本地化政策收紧（威胁，需本地部署）；Economic——货币波动大（威胁，影响定价）；Legal——AI 相关监管即将立法（重大不确定性）。SWOT 只会看到"市场大是机会"，PESTEL 却揪出了"数据主权 + AI 立法"这两个可能让整个扩张前功尽弃的宏观法律风险。公司据此把"合规可行性调研"作为扩张的第一步前置条件，而非等投入后才撞上监管墙。

## 3. 波特五力 Porter's Five Forces

**核心思想**：分析一个行业的竞争强度和盈利潜力，看五种力量——**现有竞争者的对抗、新进入者的威胁、替代品的威胁、供应商的议价能力、买方的议价能力**。核心洞察：你的盈利能力不只取决于直接对手，而是被这五种力量共同挤压。

**什么时候使用**：评估进入某行业是否有利可图；理解为什么某个行业赚钱难/容易；制定竞争战略、寻找结构性优势；投资/创业前的行业吸引力评估。

**什么时候不要使用**：非竞争性、非商业的决策；行业边界模糊或快速变化时（框架假设行业结构相对稳定，对颠覆性变化反应慢）；生态/平台型竞争（五力模型偏传统线性产业链，对网络效应、互补品刻画不足）；需要动态博弈视角时。

**优点**：把"竞争"从"就是那几个对手"扩展到五种结构性力量，视野更完整；解释盈利能力的结构性根源；对战略定位（找一个五力都较弱的位置）有指导性。

**缺点**：静态，假设行业结构稳定，对快速变化和颠覆迟钝；忽略互补品、生态、政府等第六第七种力量；偏重传统产业链，对平台/网络经济适配差；分析容易停在描述而非行动。

**AI 如何使用**：让 AI 系统评估五种力量的强弱并给依据，重点让它指出"这个行业最强的挤压力量是哪一个"——那往往是战略的关键。AI 对常见行业的五力结构有大量参照，能快速给出基线判断供你校准。

**Agent 如何使用**：竞争情报 Agent 的分析骨架——持续监测五种力量的变化信号（新进入者动态、替代技术、上下游集中度变化），生成行业结构演变报告，识别力量对比的转折点。

**Prompt 模板**：
```
用波特五力分析[目标行业]的竞争结构和盈利潜力：
逐个评估五种力量（强/中/弱 + 依据）：
1. 现有竞争强度、2. 新进入者威胁、3. 替代品威胁、4. 供应商议价力、5. 买方议价力
然后：
- 哪种力量对这个行业的盈利能力挤压最狠？
- 结构上存在"五力都较弱"的有利定位吗？在哪？
- 局限提醒：这个行业有没有五力模型抓不到的因素（网络效应、生态、监管）？
- 综合判断：这是个结构性好赚钱还是难赚钱的行业？
```

**完整案例**：某人想开一家餐厅，用五力分析行业吸引力。现有竞争：极强（餐厅遍地）。新进入者威胁：极高（开餐厅门槛低）。替代品：多（外卖、自炊、便利店）。供应商议价力：中（食材供应商分散但生鲜有波动）。买方议价力：高（顾客转换成本近乎为零）。五力几乎全是强挤压——结构性地解释了"为什么餐饮业普遍难赚钱、倒闭率高"。这不意味着不能开，而是提示：必须找到削弱某种力量的定位（如极强的差异化降低替代威胁、建立会员体系提高转换成本降低买方议价力）。五力的贡献是让创业者在投钱前就理解了自己要对抗的是整个行业的结构性引力，而非仅仅"隔壁那家店"。

## 4. 二阶思维 Second-Order Thinking

**核心思想**：不止看决策的直接后果（一阶），而是追问"然后呢？之后又会怎样？"（二阶、三阶）。霍华德·马克斯强调的思维方式。核心洞察：**人人都能看到一阶后果，竞争优势藏在别人看不到的二阶、三阶后果里**；很多决策一阶是好的、二阶却是灾难。

**什么时候使用**：任何有连锁反应、涉及他人反应、影响长期的决策；一个方案"看起来明显是好的"时（越明显越要查二阶——因为如果真那么好，别人早做了）；政策、激励机制设计（激励几乎总有二阶反效果）；评估 AI 给的"看似完美"的方案。

**什么时候不要使用**：简单、后果封闭、无连锁反应的决策（追问二阶是浪费）；已陷入过度分析、行动瘫痪时（二阶三阶可以无限推，要适可而止）；紧急止血场景（先处理一阶，二阶稍后）。

**优点**：捕捉延迟的、间接的、反直觉的后果；对抗"头痛医头"的短视；识别激励扭曲（古德哈特定律的思维工具）；是超越平庸决策者的关键区分点。

**缺点**：可以无限递归，需要判断"推到几阶够了"；后果越远越难预测，二阶推理可能沦为想象；容易滑向过度谨慎、因噎废食；对高度复杂系统，二阶预测本身可能是错的。

**AI 如何使用**：让 AI 专门追问"这个决策的二阶、三阶后果是什么""如果所有人都这么做会怎样""相关方会如何反应并适应"。这是 AI 的强项——它能快速展开多条后果链，弥补人"只看眼前一步"的本能。尤其适合让它扮演"泼冷水的二阶分析者"平衡一阶的乐观。

**Agent 如何使用**：决策/规划 Agent 在提交方案前的自检层——对每个拟采取的行动追问二阶后果，特别是"这个行动会引发环境或对手的什么适应性反应"，把只看直接效果的方案标记为高风险（与 [[01_问题定义型|逆向思考]]、Pre-mortem 协同）。

**Prompt 模板**：
```
我打算[决策/行动]。直接来看它能[预期的一阶好处]。
请做二阶及以上分析：
1. 一阶后果（直接、即时）是什么？
2. 二阶后果："然后呢"——这些一阶后果会引发什么？相关方（用户/对手/员工/市场）会如何反应和适应？
3. 三阶后果：这些反应再引发什么？
4. 重点找"一阶是好的、但二阶/三阶是坏的"的陷阱——尤其是激励扭曲（大家会不会钻空子？）
5. 有没有一阶看着平淡、但二阶三阶极好的被低估选项？
推到三阶即可，不必无限展开。
```

**完整案例**：一家公司为提升客服效率，设 KPI"每小时处理工单数"。一阶后果符合预期：处理速度上升。二阶分析（事前就该做）："然后呢"——客服为冲数量会草草结单、把复杂问题快速踢皮球。三阶：用户问题没真正解决，重复来问，总工单量不降反升，满意度下滑。这是典型的一阶好、二阶灾难的激励扭曲（古德哈特定律：指标一旦成为目标就不再是好指标）。二阶思维在决策前就能预见这条链，把 KPI 从"处理量"改为"一次解决率 + 满意度"。它的核心贡献是拦住了那些"看起来明显有效、实则养出反效果"的方案。
