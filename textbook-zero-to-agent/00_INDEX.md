## 使用方法

1. **顺序学习**，但允许两条捷径：已会编程 → 跳过第 2 章；只想先体验 → 第 1 章后直接读第 7 章再回补。
2. **每章的"项目"是硬性关卡**：项目没跑通，不进下一章。练习可以选做，项目不可以。
3. **用 AI 学 AI**：每章的"推荐 Prompt"和"推荐 Agent"就是让你把 AI 当私教。这本身就是第 1 章的核心技能。
4. **学习日志**：每章完成后写一条笔记——最重要的三个收获 + 项目遇到的最大障碍。这利用检索练习原理巩固记忆。
5. **每章末有自测题**（5 题带要点）：进下一章前先合上书回答，答不出的回头补——这也是检索练习。

## 贯穿全书的三个心法

1. **验证成本 < 生成成本，才值得委托给 AI**——这既是使用原则，也是你将来设计 Agent 的分工原则。
2. **能力边界比能力更重要**：每学一个新工具，第一个问题永远是"它在哪里会失败"。
3. **简单方案优先**：能用一次 LLM 调用解决的，不用工作流；能用工作流解决的，不用 Agent。复杂度必须被收益证明。

## 毕业标准（Agent 专家的操作性定义）

能独立完成以下全部：为一个真实业务问题判断"要不要用 Agent"；设计工具集与控制流；写出带评测集的实现；识别并防御 prompt injection；给出成本/延迟/可靠性的量化报告；向非技术人解释系统边界。
