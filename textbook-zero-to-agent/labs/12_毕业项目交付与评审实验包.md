# 第 12 章实验包：毕业项目交付与独立评审

> 配套章节：[第 12 章 专家之路](../12_专家之路.md)。本实验不替你生成一个“看起来完整”的毕业项目，而是规定项目必须交出哪些证据，并用审计器区分：材料齐全、课程暂准通过、真实使用 30 天后的最终确认。

## 1. 为什么毕业标准需要两次裁决

章节提出的最终标准是：系统真实使用超过一个月后，你仍愿意维护它。这是正确的长期标准，但课程结束当天无法验证。

因此本实验拆成两层：

1. **暂准通过（provisional pass）**：需求、实现、测试、评价、安全、成本、使用说明和维护责任都有可核验工件；
2. **最终确认（final pass）**：至少观察 30 天，补交真实使用、故障、成本、变更和“是否愿意继续维护”的记录。

没有 30 天证据，不判失败，但不能把暂准通过包装成长期价值已经得到证明。

## 2. 你要交付什么

选择一个真实高频问题，交付一个可由第三方独立审查的 Agent 项目。审查者不需要听你的现场讲解，也能回答：

- 为什么需要 AI、为什么需要 Agent，而不是更简单的方案？
- 系统的输入、输出、工具、权限和停止条件是什么？
- 代码和测试是否真的执行过？
- 评价、安全、成本和延迟是否达到你自己声明的门槛？
- 谁使用、谁维护、失败时谁接手？
- 哪些风险仍未解决？

### 机械完成标准

必须同时满足：

1. `python3 -m unittest -v` 显示 5 个审计器测试全部 `OK`；
2. `python3 capstone_audit.py submission` 返回 exit 0，并生成 `audit_report.json` 与 `audit_report.md`；
3. 所有必需工件存在，且被 `evidence_manifest.json` 显式登记；
4. 测试、评价、安全、成本四个硬门禁全部通过；
5. 独立评审六维总分至少 70/100，任一维度不得为 0；
6. 删除一个证据文件、制造路径逃逸或让关键评价失败后，审计器返回 exit 2；
7. 未满 30 天时状态只能是 `provisional_pass`，不得伪装成 `final_pass`。

## 5. 四类证据不能互相替代

| 证据 | 回答什么 | 不能被什么替代 |
|---|---|---|
| 测试报告 | 代码的确定性行为对不对 | “我演示成功过一次” |
| 评价摘要 | Agent 在目标任务分布上表现如何 | 几个顺手例子或公开 benchmark |
| 安全摘要 | 已知攻击、权限和剩余风险怎样 | 一段严厉的 system prompt |
| 成本延迟 | 系统是否可持续、用户要等多久 | 模型厂商标价或主观体感 |

审计器只核对证据契约和门禁，不会替你判断业务问题是否值得做。这个判断仍需要真实用户与独立评审。

> [!warning] 审计器不是可信执行环境
> JSON 报告可以被伪造，文件齐全也不证明代码真的在目标环境运行过。正式评审者必须从干净环境重新执行项目测试、评价和红队命令，再把新生成的证据与 manifest 对照。本页的样例 submission 只用于测试审计器，不是一个合格毕业项目本身。

## 6. `project_spec.json`：先证明问题成立

至少包含：

```json
{
  "project_name": "研究材料整理助手",
  "problem": "每周需要把分散材料整理成带来源的摘要",
  "user": "实际维护该主题的研究者",
  "frequency": "每周 2-3 次",
  "simpler_alternative": "固定模板加关键词检索",
  "why_agent": "需要根据材料状态选择搜索、读取和整理步骤",
  "owner": "项目维护者",
  "stop_conditions": ["达到工具调用上限", "缺少关键来源", "请求高风险写入"]
}
```

“因为 Agent 很先进”不是 `why_agent`。如果固定工作流足够，就应使用固定工作流。

## 7. `evidence_manifest.json`：证据目录不是装饰

```json
{
  "artifacts": [
    {"path": "evidence/test_report.json", "purpose": "证明自动化测试结果"},
    {"path": "evidence/eval_summary.json", "purpose": "证明目标任务评价结果"}
  ]
}
```

规则：

- path 必须是 submission 内相对路径；
- 不能使用 `../` 逃逸；
- manifest 中列出的文件必须存在；
- 五个必需 evidence 必须全部登记；
- 不登记的截图和口头说明不进入机械验收。

## 8. 硬门禁与评分的分工

硬门禁是“不能拿别的优点抵消”的底线：

- 自动化测试：`passed: true` 且至少 5 项；
- 评价：至少 30 个用例、总体通过率至少 80%、关键失败为 0；
- 安全：至少 10 个红队用例、关键用例通过、剩余风险非空；
- 成本延迟：必须同时填写预算和实测值，且实测不超预算。

上述数字是**课程实验门槛**，不是所有生产系统的行业标准。

评分处理硬门禁之外的质量差异：问题定义、架构、实现、评价、安全、沟通六项各 0–5 分，等权换算为 100 分。总分至少 70，且没有 0 分项，才可暂准通过。

## 10. 分步任务与里程碑

### M1：问题与最简方案

- 找到真实用户、频率和当前成本；
- 写清不用 AI、不用 Agent 的候选方案；
- 定义成功、停止和人工升级条件。

完成判据：独立评审者能复述“为什么值得做”和“什么时候不该用 Agent”。

### M2：最小可运行系统

- 固定输入输出契约；
- 实现最少工具集；
- 加预算、最大步数、权限与 trace；
- 自动化测试至少 5 项。

完成判据：一条命令运行，一条命令测试，失败不会伪装成功。

### M3：评价与安全门禁

- 30+ 目标任务用例；
- 典型、边界、对抗输入；
- 10+ 红队用例；
- 成本与延迟预算；
- 明确剩余风险。

完成判据：改一个版本后，评测脚本能机械决定允许或拒绝。

### M4：交付与维护

- 非技术用户说明；
- 维护责任、故障处理和退役条件；
- manifest 登记证据；
- 独立评审打分。

完成判据：作者不在场时，第三方能运行、评审并定位失败。

### M5：30 天后验确认

- 记录实际使用天数、任务数、失败、人工接管、成本和变更；
- 回答是否仍愿意维护，以及原因；
- 若没人使用，诚实写明，不用“技术完成”替代价值证明。

## 11. 常见不合格样例

| 表面上有什么 | 实际缺什么 | 审计结果 |
|---|---|---|
| 漂亮 Demo 视频 | 可重复测试与输入数据 | hard gate fail |
| 30 条全由模型合成的简单题 | 真实失败与冻结验证集 | 人工评审应降低评价分 |
| 红队通过率 100% | 剩余风险为空或写“无风险” | hard gate fail |
| 平均成本很低 | 没有预算上限或 P95 延迟 | hard gate fail |
| README 很长 | 用户说明、维护责任不清 | 相关维度低分 |
| 代码很多 | `why_agent` 只是“更智能” | 问题定义不合格 |

## 12. 评分 rubric（100 分）

| 维度 | 5 分表现 | 3 分表现 | 0 分表现 |
|---|---|---|---|
| 问题定义 | 真实用户、频率、替代方案和止损清楚 | 问题成立但证据较弱 | 没有真实问题或用户 |
| 架构 | 最简、边界明确、复杂度有证据 | 基本可解释 | 堆框架且说不清控制流 |
| 实现 | 可运行、可测试、失败受控 | 主流程可用 | 只能演示或依赖作者现场修 |
| 评价 | 数据可信、版本可比、门禁明确 | 有 30 条但覆盖一般 | 只有 vibe check |
| 安全 | 权限、红队、剩余风险完整 | 有基本防线 | 只靠 prompt 或发生越权 |
| 沟通维护 | 用户能用、维护者能接手 | 文档基本齐全 | 作者不在就无法运行 |

评审者必须在 `review_scores.json` 为每项写 `score` 和一句 `reason`。审计器检查分数，不替评审者编造理由。

真实项目中，`review_scores.json` 应由未参与项目实现的人或独立 Agent 生成；作者自评只能作为补充，不能冒充独立评审。

from __future__ import annotations

import tempfile
import unittest
from pathlib import Path

from capstone_audit import audit_submission
from make_sample_submission import create_submission


class CapstoneAuditTests(unittest.TestCase):
    def setUp(self) -> None:
        self.temp = tempfile.TemporaryDirectory()
        self.root = Path(self.temp.name) / "submission"
        create_submission(self.root)

    def tearDown(self) -> None:
        self.temp.cleanup()

    def test_reference_submission_is_provisional(self) -> None:
        result = audit_submission(self.root)
        self.assertEqual(result["status"], "provisional_pass")

    def test_missing_required_file_fails(self) -> None:
        (self.root / "user_guide.md").unlink()
        self.assertEqual(audit_submission(self.root)["status"], "fail")

    def test_manifest_path_escape_fails(self) -> None:
        manifest = self.root / "evidence_manifest.json"
        manifest.write_text('{"artifacts":[{"path":"../secret.txt","purpose":"bad"}]}', encoding="utf-8")
        self.assertEqual(audit_submission(self.root)["status"], "fail")

    def test_critical_eval_failure_fails(self) -> None:
        path = self.root / "evidence/eval_summary.json"
        path.write_text('{"cases":30,"pass_rate":0.95,"critical_failures":1}', encoding="utf-8")
        self.assertEqual(audit_submission(self.root)["status"], "fail")

    def test_low_review_score_fails(self) -> None:
        path = self.root / "review_scores.json"
        path.write_text('{"problem":{"score":1,"reason":"weak"}}', encoding="utf-8")
        self.assertEqual(audit_submission(self.root)["status"], "fail")


if __name__ == "__main__":
    unittest.main()

## 14. 参考实现

<!-- reference-file: capstone_audit.py -->
```python
from __future__ import annotations

import argparse
import json
from pathlib import Path
from typing import Any


REQUIRED_FILES = {
    "project_spec.json",
    "architecture.md",
    "user_guide.md",
    "maintenance.md",
    "remaining_risks.md",
    "evidence_manifest.json",
    "review_scores.json",
    "src/main.py",
    "tests/test_main.py",
    "evidence/test_report.json",
    "evidence/eval_summary.json",
    "evidence/security_summary.json",
    "evidence/cost_latency.json",
    "evidence/trace_sample.jsonl",
}
REQUIRED_EVIDENCE = {path for path in REQUIRED_FILES if path.startswith("evidence/")}
REVIEW_DIMENSIONS = {"problem", "architecture", "implementation", "evaluation", "safety", "communication"}


def load_json(path: Path) -> dict[str, Any]:
    return json.loads(path.read_text(encoding="utf-8"))


def inside(root: Path, relative: str) -> bool:
    if Path(relative).is_absolute():
        return False
    base = root.resolve()
    target = (base / relative).resolve()
    return target == base or base in target.parents


def audit_submission(root: Path) -> dict[str, Any]:
    errors: list[str] = []
    checks: dict[str, bool] = {}
    missing = sorted(path for path in REQUIRED_FILES if not (root / path).is_file())
    checks["required_files"] = not missing
    if missing:
        errors.append(f"缺少必需文件：{missing}")
        return {"status": "fail", "score": 0.0, "checks": checks, "errors": errors}

    spec = load_json(root / "project_spec.json")
    spec_fields = {"project_name", "problem", "user", "frequency", "simpler_alternative", "why_agent", "owner", "stop_conditions"}
    checks["project_spec"] = not (spec_fields - spec.keys()) and bool(spec.get("stop_conditions"))
    if not checks["project_spec"]:
        errors.append("project_spec 字段不完整")

    manifest = load_json(root / "evidence_manifest.json")
    artifacts = manifest.get("artifacts", [])
    listed: set[str] = set()
    manifest_ok = isinstance(artifacts, list) and bool(artifacts)
    for item in artifacts if isinstance(artifacts, list) else []:
        relative = item.get("path") if isinstance(item, dict) else None
        if not isinstance(relative, str) or not inside(root, relative) or not (root / relative).is_file():
            manifest_ok = False
            errors.append(f"非法或不存在的 manifest path：{relative}")
        else:
            listed.add(relative)
    if not REQUIRED_EVIDENCE <= listed:
        manifest_ok = False
        errors.append(f"manifest 未登记必需证据：{sorted(REQUIRED_EVIDENCE - listed)}")
    checks["evidence_manifest"] = manifest_ok

    tests = load_json(root / "evidence/test_report.json")
    checks["tests"] = tests.get("passed") is True and int(tests.get("tests", 0)) >= 5
    if not checks["tests"]:
        errors.append("自动化测试硬门禁失败")

    evaluation = load_json(root / "evidence/eval_summary.json")
    checks["evaluation"] = (
        int(evaluation.get("cases", 0)) >= 30
        and float(evaluation.get("pass_rate", 0)) >= 0.8
        and int(evaluation.get("critical_failures", 1)) == 0
    )
    if not checks["evaluation"]:
        errors.append("评价硬门禁失败")

    security = load_json(root / "evidence/security_summary.json")
    checks["security"] = (
        int(security.get("cases", 0)) >= 10
        and security.get("critical_pass") is True
        and bool(security.get("remaining_risks"))
    )
    if not checks["security"]:
        errors.append("安全硬门禁失败")

    cost = load_json(root / "evidence/cost_latency.json")
    required_cost = {"measured_average_cost", "max_average_cost", "measured_p95_latency_ms", "max_p95_latency_ms"}
    checks["cost_latency"] = required_cost <= cost.keys()
    if checks["cost_latency"]:
        checks["cost_latency"] = (
            float(cost["measured_average_cost"]) <= float(cost["max_average_cost"])
            and float(cost["measured_p95_latency_ms"]) <= float(cost["max_p95_latency_ms"])
        )
    if not checks["cost_latency"]:
        errors.append("成本或延迟硬门禁失败")

    reviews = load_json(root / "review_scores.json")
    review_ok = REVIEW_DIMENSIONS <= reviews.keys()
    scores: list[float] = []
    for dimension in REVIEW_DIMENSIONS:
        item = reviews.get(dimension, {})
        score = item.get("score") if isinstance(item, dict) else None
        reason = item.get("reason") if isinstance(item, dict) else None
        if not isinstance(score, (int, float)) or not 0 <= score <= 5 or not str(reason or "").strip():
            review_ok = False
        else:
            scores.append(float(score))
    score_100 = sum(scores) / (len(REVIEW_DIMENSIONS) * 5) * 100 if len(scores) == len(REVIEW_DIMENSIONS) else 0.0
    checks["independent_review"] = review_ok and score_100 >= 70 and all(score > 0 for score in scores)
    if not checks["independent_review"]:
        errors.append("独立评审分数或理由不合格")

    passed = all(checks.values())
    status = "fail"
    if passed:
        review_30 = root / "evidence/30_day_review.json"
        if review_30.is_file():
            long_term = load_json(review_30)
            final = int(long_term.get("days_observed", 0)) >= 30 and long_term.get("willing_to_maintain") is True
            status = "final_pass" if final else "provisional_pass"
        else:
            status = "provisional_pass"
    return {"status": status, "score": round(score_100, 1), "checks": checks, "errors": errors}


def write_report(root: Path, result: dict[str, Any]) -> None:
    (root / "audit_report.json").write_text(json.dumps(result, ensure_ascii=False, indent=2), encoding="utf-8")
    lines = [
        "# 毕业项目审计报告",
        "",
        f"- 状态：{result['status']}",
        f"- 独立评审分：{result['score']:.1f}/100",
        "",
        "## 硬门禁",
    ]
    lines.extend(f"- [{'x' if passed else ' '}] {name}" for name, passed in result["checks"].items())
    lines.extend(["", "## 问题"])
    lines.extend(f"- {error}" for error in result["errors"])
    if not result["errors"]:
        lines.append("- 无")
    if result["status"] == "provisional_pass":
        lines.extend(["", "> 当前只是课程暂准通过；缺少至少 30 天真实使用证据，不能声称长期价值已验证。"])
    (root / "audit_report.md").write_text("\n".join(lines) + "\n", encoding="utf-8")


def main() -> int:
    parser = argparse.ArgumentParser()
    parser.add_argument("submission", type=Path)
    args = parser.parse_args()
    result = audit_submission(args.submission)
    write_report(args.submission, result)
    print(result["status"])
    return 0 if result["status"] in {"provisional_pass", "final_pass"} else 2


if __name__ == "__main__":
    raise SystemExit(main())
```

from __future__ import annotations

import json
from pathlib import Path


def write_json(path: Path, data: dict) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(data, ensure_ascii=False, indent=2), encoding="utf-8")


def create_submission(root: Path) -> None:
    (root / "src").mkdir(parents=True, exist_ok=True)
    (root / "tests").mkdir(exist_ok=True)
    (root / "evidence").mkdir(exist_ok=True)
    write_json(root / "project_spec.json", {
        "project_name": "研究材料整理助手",
        "problem": "每周整理分散材料并保留来源",
        "user": "实际研究者",
        "frequency": "每周 2-3 次",
        "simpler_alternative": "固定模板与关键词检索",
        "why_agent": "需要根据材料状态选择搜索、读取和整理步骤",
        "owner": "项目维护者",
        "stop_conditions": ["工具上限", "关键来源缺失", "高风险写入"],
    })

## 17. 30 天后最终确认格式

`evidence/30_day_review.json` 至少包含：

```json
{
  "days_observed": 30,
  "real_tasks": 42,
  "active_users": 2,
  "failures": 5,
  "human_takeovers": 3,
  "maintenance_changes": 4,
  "willing_to_maintain": true,
  "reason": "每周仍节省重复整理时间，失败可定位"
}
```

数字必须来自真实记录。把天数写成 30 不会自动证明价值；独立评审仍应检查任务是否真实、失败是否被隐藏、维护成本是否可接受。

## 18. 学习复盘

1. 你的项目最可能在哪一项硬门禁上失败？为什么此前没有发现？
2. 如果删掉 Agent，改成固定工作流，会失去什么、又会减少什么风险？
3. 30 天后，什么证据会让你主动退役这个项目，而不是继续投入沉没成本？

毕业不是“十二章读完”，而是你能用证据判断一个系统应当发布、继续、降级还是停止。
