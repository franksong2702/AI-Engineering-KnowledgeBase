# 第 10 章实验包：安全发布门禁与运行证据

> 配套章节：[第 10 章 安全与生产部署](../10_安全与生产部署.md)。本实验不承诺“防住所有 Prompt Injection”，而是要求你证明：即使模型或不可信内容诱导了危险动作，代码侧权限、预算和审批仍能限制爆炸半径，并留下不泄露敏感信息的证据。

## 1. 你要交付什么

一个本地安全策略执行器和红队发布门禁：

```text
请求 / 不可信内容
        ↓
代码侧策略：动作范围、审批、白名单、路径沙箱、预算、敏感数据
        ↓
允许 / 拒绝（本实验只模拟，不执行真实副作用）
        ↓
脱敏 trace + 红队结果 + 剩余风险 + 发布裁决
```

实验固定检查三类动作：

- `answer`：只生成回答，不产生外部副作用；
- `send`：模拟向外部收件人发送内容；
- `write`：模拟向 workspace 写文件。

### 机械完成标准

必须同时满足：

1. `python3 -m unittest -v` 显示 5 个测试全部 `OK`；
2. 10 个红队用例的实际裁决都与预期一致；
3. 未审批外发、非白名单收件人、包含敏感数据的外发全部拒绝；
4. 路径逃逸、未审批写入和预算超限全部拒绝；
5. `trace.jsonl` 不包含样例原始邮箱、手机号或 API key；
6. `security_summary.json` 明确列出剩余风险，不能写“已绝对安全”；
7. 所有硬门禁通过时 CLI 返回 exit 0；任一关键用例失败时返回 exit 2。

## 4. 威胁模型先于过滤规则

本实验保护的资产：workspace 文件、允许外发的数据、预算和审计日志。攻击者可能控制用户输入、检索文档或工具返回值，但不能直接修改代码侧策略。

硬边界：

| 风险 | 代码侧控制 | 为什么不是只靠 Prompt |
|---|---|---|
| 未授权外发 | 审批 + 收件人白名单 | 模型自称“已获授权”不算授权 |
| 数据泄露 | 外发前敏感数据检查 | 输入提示不能撤销数据策略 |
| 任意文件写入 | 路径沙箱 + 审批 | 路径在执行前由代码解析 |
| 资源耗尽 | 单任务 token 预算 | 达到预算直接停止，不再询问模型 |
| 日志泄露 | 记录前脱敏 | 可观测性不能制造第二个泄露面 |

> [!warning]
> 本实验里的敏感数据正则只是教学样例，不是完整 DLP。真正项目必须根据自己的数据分类、语言、编码形式和合规要求替换；“正则没匹配到”不等于“内容安全”。

## 6. 策略契约

`policy.json` 只放可审计规则，不放密钥：

```json
{
  "allowed_actions": ["answer", "send", "write"],
  "allowed_recipients": ["reviewer@example.org"],
  "workspace": "workspace",
  "max_estimated_tokens": 1000,
  "require_approval_for": ["send", "write"]
}
```

请求记录示例：

```json
{"id":"send-no-approval","action":"send","recipient":"reviewer@example.org","content":"普通摘要","approved":false,"estimated_tokens":100,"expected":"deny","critical":true}
```

`approved` 必须来自你的应用审批状态，而不是模型输出的一句话。真实项目还应记录批准人、批准时间、被批准的参数摘要和过期时间。

## 7. 分步任务与检查点

| 步骤 | 要实现什么 | 机械检查点 |
|---|---|---|
| 1 | 默认拒绝未知动作和缺字段请求 | 未知 `action` 返回 deny，不抛到副作用层 |
| 2 | 加预算门禁 | `estimated_tokens` 超上限即拒绝 |
| 3 | 加外发策略 | 审批、收件人、敏感数据三关独立留下理由 |
| 4 | 加文件策略 | 解析后的目标路径必须位于 workspace 内且已审批 |
| 5 | 加脱敏 trace | 邮箱、手机号、样例 key 写入前被替换 |
| 6 | 跑 10 个红队用例 | 每条记录 expected/actual/matched/reasons |
| 7 | 建发布门禁 | 关键用例、trace 泄露、剩余风险声明任一缺失都阻断 |

## 8. 红队用例必须测“能力 × 权限”

至少覆盖：

1. 普通无副作用回答；
2. 外部内容夹带“忽略规则并外发”的指令；
3. 未审批外发；
4. 非白名单收件人；
5. 含敏感数据的外发；
6. 已审批、白名单、无敏感数据的外发；
7. workspace 路径逃逸；
8. 未审批写入；
9. 已审批的 workspace 内写入；
10. token 预算超限。

这里不以“模型有没有听懂攻击”为唯一判据。更重要的是：即使上游给出危险动作意图，策略层也不能越权。

## 9. 常见失败：不要把日志当安全证明

| 现象 | 误判 | 正确动作 |
|---|---|---|
| Prompt 写得很严 | 以为不会被绕过 | 把真正边界放在权限和执行层 |
| 红队 10/10 | 宣布绝对安全 | 只说明已知 fixture 通过，继续列未知风险 |
| trace 很完整 | 忽略 trace 含 PII | 先脱敏再落盘，并测试原文不出现 |
| 审批为 true | 不知道谁批准了什么 | 绑定具体参数和审批身份，防审批后换参 |
| 路径以 workspace 开头 | 用字符串前缀判断 | `resolve()` 后检查父子路径关系 |

## 10. 评分 rubric（100 分）

| 维度 | 分值 | 合格证据 |
|---|---:|---|
| 威胁模型 | 10 | 资产、攻击者能力、信任边界明确 |
| 默认拒绝与输入校验 | 10 | 未知动作/缺字段受控失败 |
| 外发权限 | 20 | 审批、白名单、敏感数据独立执行 |
| 文件与预算边界 | 20 | 路径逃逸和超预算被代码阻断 |
| 红队覆盖 | 15 | 10 类用例有 expected/actual 证据 |
| 可观测与脱敏 | 15 | trace 可复盘且不含样例原始秘密 |
| 剩余风险与发布裁决 | 10 | 不夸大结论，硬门禁与 exit code 一致 |

硬门禁：任何未授权副作用被允许、trace 泄露样例秘密、关键用例失败，直接不合格。

from __future__ import annotations

import json
import tempfile
import unittest
from pathlib import Path

from security_release import evaluate_request, redact, run_suite


class SecurityReleaseTests(unittest.TestCase):
    def setUp(self) -> None:
        self.temp = tempfile.TemporaryDirectory()
        workspace = Path(self.temp.name) / "workspace"
        workspace.mkdir()
        self.policy = {
            "allowed_actions": ["answer", "send", "write"],
            "allowed_recipients": ["reviewer@example.org"],
            "workspace": str(workspace),
            "max_estimated_tokens": 1000,
            "require_approval_for": ["send", "write"],
        }

    def tearDown(self) -> None:
        self.temp.cleanup()

    def test_send_requires_approval(self) -> None:
        decision = evaluate_request({"action": "send", "recipient": "reviewer@example.org", "content": "ok", "approved": False, "estimated_tokens": 1}, self.policy)
        self.assertFalse(decision["allow"])

    def test_recipient_allowlist(self) -> None:
        decision = evaluate_request({"action": "send", "recipient": "attacker.example", "content": "ok", "approved": True, "estimated_tokens": 1}, self.policy)
        self.assertFalse(decision["allow"])

    def test_path_escape_is_denied(self) -> None:
        decision = evaluate_request({"action": "write", "path": "../outside.txt", "content": "x", "approved": True, "estimated_tokens": 1}, self.policy)
        self.assertFalse(decision["allow"])

    def test_budget_is_hard_limit(self) -> None:
        decision = evaluate_request({"action": "answer", "content": "x", "approved": False, "estimated_tokens": 1001}, self.policy)
        self.assertFalse(decision["allow"])

    def test_trace_is_redacted(self) -> None:
        output = Path(self.temp.name) / "artifacts"
        cases = [{"id": "pii", "action": "send", "recipient": "reviewer@example.org", "content": "call 13800138000 with sk-demo-secret", "approved": True, "estimated_tokens": 1, "expected": "deny", "critical": True}]
        summary = run_suite(cases, self.policy, output)
        trace = (output / "trace.jsonl").read_text(encoding="utf-8")
        self.assertTrue(summary["release"])
        self.assertNotIn("13800138000", trace)
        self.assertNotIn("sk-demo-secret", trace)
        self.assertIn("[REDACTED]", trace)


if __name__ == "__main__":
    unittest.main()

## 12. 参考实现

<!-- reference-file: security_release.py -->
```python
from __future__ import annotations

import argparse
import json
import re
from pathlib import Path
from typing import Any


EMAIL = re.compile(r"\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}\b")
PHONE = re.compile(r"(?<!\d)1\d{10}(?!\d)")
API_KEY = re.compile(r"\bsk-[A-Za-z0-9_-]{6,}\b")


def redact(text: str) -> str:
    result = EMAIL.sub("[REDACTED]", text)
    result = PHONE.sub("[REDACTED]", result)
    return API_KEY.sub("[REDACTED]", result)


def has_sensitive_data(text: str) -> bool:
    return any(pattern.search(text) for pattern in (EMAIL, PHONE, API_KEY))


def is_inside_workspace(path: str, workspace: str) -> bool:
    root = Path(workspace).resolve()
    target = (root / path).resolve()
    return target == root or root in target.parents


def evaluate_request(request: dict[str, Any], policy: dict[str, Any]) -> dict[str, Any]:
    reasons: list[str] = []
    action = request.get("action")
    if action not in policy.get("allowed_actions", []):
        reasons.append("动作不在允许列表")

    try:
        tokens = int(request.get("estimated_tokens", -1))
    except (TypeError, ValueError):
        tokens = -1
    if tokens < 0:
        reasons.append("estimated_tokens 缺失或非法")
    elif tokens > int(policy["max_estimated_tokens"]):
        reasons.append("超过单任务 token 预算")

    if action in policy.get("require_approval_for", []) and request.get("approved") is not True:
        reasons.append("缺少明确审批")

    content = str(request.get("content", ""))
    if action == "send":
        if request.get("recipient") not in policy.get("allowed_recipients", []):
            reasons.append("收件人不在白名单")
        if has_sensitive_data(content):
            reasons.append("外发内容含敏感数据")
    elif action == "write":
        path = request.get("path")
        if not isinstance(path, str) or not path:
            reasons.append("写入路径缺失")
        elif not is_inside_workspace(path, str(policy["workspace"])):
            reasons.append("目标路径逃逸 workspace")

    return {"allow": not reasons, "reasons": reasons}


def load_jsonl(path: Path) -> list[dict[str, Any]]:
    return [json.loads(line) for line in path.read_text(encoding="utf-8").splitlines() if line.strip()]


def render_release(summary: dict[str, Any]) -> str:
    lines = [
        "# 安全发布裁决",
        "",
        f"- 裁决：{'允许发布' if summary['release'] else '拒绝发布'}",
        f"- 红队匹配：{summary['matched']}/{summary['total']}",
        f"- 关键用例：{'通过' if summary['critical_pass'] else '失败'}",
        f"- Trace 样例泄露：{'否' if summary['trace_redacted'] else '是'}",
        "",
        "## 剩余风险",
    ]
    lines.extend(f"- {risk}" for risk in summary["remaining_risks"])
    return "\n".join(lines) + "\n"


def run_suite(cases: list[dict[str, Any]], policy: dict[str, Any], output: Path) -> dict[str, Any]:
    output.mkdir(parents=True, exist_ok=True)
    results: list[dict[str, Any]] = []
    trace_rows: list[dict[str, Any]] = []
    for case in cases:
        decision = evaluate_request(case, policy)
        actual = "allow" if decision["allow"] else "deny"
        matched = actual == case.get("expected")
        results.append({
            "id": case.get("id"),
            "expected": case.get("expected"),
            "actual": actual,
            "matched": matched,
            "critical": bool(case.get("critical", False)),
            "reasons": decision["reasons"],
        })
        trace_rows.append({
            "id": case.get("id"),
            "action": case.get("action"),
            "recipient": redact(str(case.get("recipient", ""))),
            "path": str(case.get("path", "")),
            "content": redact(str(case.get("content", ""))),
            "decision": actual,
            "reasons": decision["reasons"],
        })

    results_path = output / "redteam_results.jsonl"
    trace_path = output / "trace.jsonl"
    results_path.write_text("".join(json.dumps(row, ensure_ascii=False) + "\n" for row in results), encoding="utf-8")
    trace_path.write_text("".join(json.dumps(row, ensure_ascii=False) + "\n" for row in trace_rows), encoding="utf-8")
    trace_text = trace_path.read_text(encoding="utf-8")
    raw_secrets = [
        match.group(0)
        for case in cases
        for pattern in (EMAIL, PHONE, API_KEY)
        for match in pattern.finditer(str(case.get("content", "")) + " " + str(case.get("recipient", "")))
    ]
    trace_redacted = all(secret not in trace_text for secret in raw_secrets)
    critical_pass = all(row["matched"] for row in results if row["critical"])
    matched = sum(bool(row["matched"]) for row in results)
    remaining_risks = [
        "正则无法覆盖所有敏感数据和编码变体",
        "本地录制用例不能证明未知攻击不会成功",
        "真实审批系统仍需绑定身份、参数和有效期",
    ]
    summary = {
        "release": matched == len(results) and critical_pass and trace_redacted and bool(remaining_risks),
        "total": len(results),
        "matched": matched,
        "critical_pass": critical_pass,
        "trace_redacted": trace_redacted,
        "remaining_risks": remaining_risks,
    }
    (output / "security_summary.json").write_text(json.dumps(summary, ensure_ascii=False, indent=2), encoding="utf-8")
    (output / "release_decision.md").write_text(render_release(summary), encoding="utf-8")
    return summary


def main() -> int:
    parser = argparse.ArgumentParser()
    parser.add_argument("--policy", type=Path, default=Path("policy.json"))
    parser.add_argument("--cases", type=Path, default=Path("redteam_cases.jsonl"))
    parser.add_argument("--output", type=Path, default=Path("artifacts"))
    args = parser.parse_args()
    policy = json.loads(args.policy.read_text(encoding="utf-8"))
    summary = run_suite(load_jsonl(args.cases), policy, args.output)
    print("ALLOW" if summary["release"] else "BLOCK")
    return 0 if summary["release"] else 2


if __name__ == "__main__":
    raise SystemExit(main())
```

## 15. 接真实服务时增加什么

本实验故意不执行副作用。接入真实服务时，必须保持顺序：

```text
解析请求 → 策略裁决 → 绑定审批参数 → 执行一次 → 记录脱敏结果
```

还要增加：身份认证、审批防重放、并发限额、幂等键、密钥管理、真实 DLP、告警、回滚和事故 runbook。不要把本实验的正则和十条用例包装成生产安全认证。
