# 第 9 章实验包：给 Agent 建版本对比评测门禁

> 配套章节：[第 9 章 评测与可靠性工程](../09_评测与可靠性工程.md)。本实验不再罗列评价方法，而是把“测试集 → 逐条评分 → 版本比较 → 发布裁决 → 证据报告”连成一条可运行的链。

## 1. 你要交付什么

为一个简化的研究助理 Agent 建评测门禁。实验不调用真实模型，而是使用两组已录制的 baseline/candidate 运行记录，避免把模型波动和 API 故障混入评测代码。

最终系统要回答五个问题：

1. 每个用例为什么通过或失败？
2. candidate 相对 baseline 提升了什么、回归了什么？
3. 关键用例是否每次都通过？
4. 成本和延迟是否越过预算？
5. 这次版本到底能不能发布？

### 机械完成标准

必须同时满足：

1. `python3 -m unittest -v` 显示 5 个测试全部 `OK`；
2. 每个用例至少有 3 次运行记录，报告使用通过率而不是单次成败；
3. `details.jsonl` 保留每次运行的评分理由；
4. 任一 `critical` 用例发生回归时，整体平均分再高也必须拒绝发布；
5. candidate 的平均成本和 P95 延迟超过配置阈值时必须拒绝发布；
6. CLI 为样例 candidate 返回 exit 0，并生成 `summary.json`、`report.md`；
7. 修改 fixture 制造关键回归后，CLI 返回 exit 2。


### 运行记录

同一 `case_id` 和 `version` 至少记录 3 个 `run`：

```json
{"case_id":"cite","version":"candidate","run":1,"answer":"结论附来源","tools":["search","open"],"latency_ms":620,"cost":0.004}
```

本实验把“模型执行”与“评价执行”分开。以后接真实 Agent 时，只替换运行记录的生成方式，不重写门禁。

## 6. 分步任务与检查点

| 步骤 | 要实现什么 | 机械检查点 |
|---|---|---|
| 1 | 校验 cases/runs 的必需字段与重复记录 | 缺字段、未知 `case_id`、重复 `(case_id, version, run)` 都报错 |
| 2 | 写代码评分器 | 必需词、禁用词、工具调用上限分别留下布尔结果与理由 |
| 3 | 按用例聚合 | 每个用例显示 runs、passed_runs、pass_rate |
| 4 | 计算运行指标 | 输出 overall pass rate、平均成本、P95 延迟 |
| 5 | 比较两个版本 | 找出提升、回归和关键回归，不只比较一个平均数 |
| 6 | 建发布门禁 | 质量、关键用例、成本、延迟任一越界都拒绝 |
| 7 | 写证据 | JSON 给机器，Markdown 给人；两者裁决必须一致 |

建议每完成两步提交一次 Git，提交信息写清新获得的能力。

## 7. 阈值不是“真理”，而是发布契约

样例 `thresholds.json`：

```json
{
  "min_candidate_pass_rate": 0.8,
  "max_overall_drop": 0.0,
  "max_case_drop": 0.34,
  "max_average_cost": 0.01,
  "max_p95_latency_ms": 1200
}
```

这些数字只是**实验编排值**，不是行业标准。真实项目必须根据风险、用户承诺和历史基线重新定阈值。

## 8. 校准主观评分器

本实验先用代码评分器保证结果可复现。接入 LLM-as-judge 时，不要直接把它的分数加入发布门禁。至少补一份 `judge_calibration.jsonl`：

```json
{"sample_id":"s1","human_label":"pass","judge_label":"pass"}
{"sample_id":"s2","human_label":"fail","judge_label":"pass"}
```

先计算与人工标签的一致率，并检查错误集中在哪类样本。未经校准的 Judge 只能作为观察信号，不能独自决定发布。

## 9. 常见失败：按证据链排查

| 现象 | 常见原因 | 排查顺序 |
|---|---|---|
| 平均分升高但关键任务坏了 | 只比较 overall | 看 critical cases → 看逐用例 drop → 再看平均数 |
| 重跑数字变了 | 输入记录未冻结或重复键未拦截 | 校验文件 hash → 检查 `(case, version, run)` 唯一性 |
| 报告说发布、CLI 却拒绝 | 人读报告和机器裁决各算一遍 | 只生成一次 decision，再渲染两种格式 |
| P95 看起来异常 | 样本少或排序实现错误 | 打印原始延迟 → 核对分位数定义 → 扩大样本 |
| candidate 全赢 | 测试集被拿去调参 | 检查冻结集、时间戳和数据来源；保留未参与调优的验证集 |

## 10. 评分 rubric（100 分）

| 维度 | 分值 | 合格证据 |
|---|---:|---|
| 数据契约与校验 | 15 | 非法输入明确失败，不静默跳过 |
| 逐条评分可解释性 | 20 | 每次运行有 checks 和 reasons |
| 非确定性处理 | 15 | 每用例至少 3 次，按通过率聚合 |
| 版本比较 | 15 | 能列提升、回归、关键回归 |
| 发布门禁 | 20 | 质量/关键/成本/延迟分别裁决 |
| 证据产物 | 10 | JSONL、JSON、Markdown 相互一致 |
| 测试与可复现性 | 5 | 5 项测试通过，一条命令复现 |

硬门禁：关键回归未阻断、记录无法追溯、报告与 exit code 不一致，直接不合格，不用总分抵消。

```python
from eval_gate import decide_release, percentile, score_run, summarize

class EvalGateTests(unittest.TestCase):
    def test_score_run_explains_failure(self) -> None:
        result = score_run(CASES[0], {"answer": "编造内容", "tools": [], "latency_ms": 1, "cost": 0})
        self.assertFalse(result["passed"])
        self.assertGreaterEqual(len(result["reasons"]), 2)

        self.assertEqual(percentile([100, 200, 300, 400], 0.95), 400)

    def test_summarize_uses_repeated_runs(self) -> None:
        runs = []
        for index, answer in enumerate(["来源", "来源", "缺失"], 1):
            runs.append({"case_id": "critical", "run": index, "answer": answer, "tools": [], "latency_ms": 10, "cost": 0.001})

            runs.append({"case_id": "normal", "run": index, "answer": "结论", "tools": [], "latency_ms": 10, "cost": 0.001})
```

```python
from __future__ import annotations

import argparse
import json
import math
from pathlib import Path
from typing import Any


def load_jsonl(path: Path) -> list[dict[str, Any]]:
    return [json.loads(line) for line in path.read_text(encoding="utf-8").splitlines() if line.strip()]


def write_json(path: Path, data: Any) -> None:
    path.write_text(json.dumps(data, ensure_ascii=False, indent=2), encoding="utf-8")


def percentile(values: list[float], quantile: float) -> float:
    if not values:
        return 0.0
    ordered = sorted(values)
    index = max(0, math.ceil(len(ordered) * quantile) - 1)
    return ordered[index]


def score_run(case: dict[str, Any], run: dict[str, Any]) -> dict[str, Any]:
    answer = str(run.get("answer", ""))
    tools = list(run.get("tools", []))
    checks: dict[str, bool] = {}
    reasons: list[str] = []

    for term in case.get("required_terms", []):
        key = f"required:{term}"
        checks[key] = term in answer
        if not checks[key]:
            reasons.append(f"缺少必需词：{term}")
    for term in case.get("forbidden_terms", []):
        key = f"forbidden:{term}"
        checks[key] = term not in answer
        if not checks[key]:
            reasons.append(f"包含禁用词：{term}")
    checks["tool_budget"] = len(tools) <= int(case.get("max_tools", 999))
    if not checks["tool_budget"]:
        reasons.append(f"工具调用 {len(tools)} 次，超过上限 {case['max_tools']}")

    return {
        **run,
        "passed": all(checks.values()),
        "checks": checks,
        "reasons": reasons,
    }


def validate_inputs(cases: list[dict[str, Any]], runs: list[dict[str, Any]]) -> None:
    case_ids = {case.get("id") for case in cases}
    if None in case_ids or len(case_ids) != len(cases):
        raise ValueError("case id 缺失或重复")
    seen: set[tuple[str, int]] = set()
    for run in runs:
        required = {"case_id", "run", "answer", "tools", "latency_ms", "cost"}
        missing = required - run.keys()
        if missing:
            raise ValueError(f"运行记录缺字段：{sorted(missing)}")
        if run["case_id"] not in case_ids:
            raise ValueError(f"未知 case_id：{run['case_id']}")
        key = (str(run["case_id"]), int(run["run"]))
        if key in seen:
            raise ValueError(f"重复运行键：{key}")
        seen.add(key)


def summarize(
    cases: list[dict[str, Any]], runs: list[dict[str, Any]]
) -> tuple[dict[str, Any], list[dict[str, Any]]]:
    validate_inputs(cases, runs)
    case_map = {case["id"]: case for case in cases}
    details = [score_run(case_map[run["case_id"]], run) for run in runs]
    case_summary: dict[str, Any] = {}
    for case in cases:
        rows = [row for row in details if row["case_id"] == case["id"]]
        if len(rows) < 3:
            raise ValueError(f"{case['id']} 少于 3 次运行")
        passed = sum(bool(row["passed"]) for row in rows)
        case_summary[case["id"]] = {
            "critical": bool(case.get("critical", False)),
            "runs": len(rows),
            "passed_runs": passed,
            "pass_rate": passed / len(rows),
        }

    total_passed = sum(bool(row["passed"]) for row in details)
    critical_all_pass = all(
        item["pass_rate"] == 1.0
        for item in case_summary.values()
        if item["critical"]
    )
    summary = {
        "overall_pass_rate": total_passed / len(details) if details else 0.0,
        "critical_all_pass": critical_all_pass,
        "average_cost": sum(float(row["cost"]) for row in details) / len(details) if details else 0.0,
        "p95_latency_ms": percentile([float(row["latency_ms"]) for row in details], 0.95),
        "cases": case_summary,
    }
    return summary, details


def decide_release(
    baseline: dict[str, Any], candidate: dict[str, Any], thresholds: dict[str, Any]
) -> tuple[bool, list[str]]:
    reasons: list[str] = []
    if candidate["overall_pass_rate"] < float(thresholds["min_candidate_pass_rate"]):
        reasons.append("候选版本总体通过率低于门槛")
    drop = baseline["overall_pass_rate"] - candidate["overall_pass_rate"]
    if drop > float(thresholds["max_overall_drop"]):
        reasons.append(f"总体通过率回归 {drop:.3f}")
    if not candidate["critical_all_pass"]:
        reasons.append("关键用例没有保持全通过")

    max_case_drop = float(thresholds["max_case_drop"])
    for case_id, base_case in baseline.get("cases", {}).items():
        if case_id not in candidate.get("cases", {}):
            reasons.append(f"候选版本缺少用例：{case_id}")
            continue
        case_drop = base_case["pass_rate"] - candidate["cases"][case_id]["pass_rate"]
        if case_drop > max_case_drop:
            reasons.append(f"用例 {case_id} 回归 {case_drop:.3f}")
    if candidate["average_cost"] > float(thresholds["max_average_cost"]):
        reasons.append("候选版本平均成本超过上限")
    if candidate["p95_latency_ms"] > float(thresholds["max_p95_latency_ms"]):
        reasons.append("候选版本 P95 延迟超过上限")
    return not reasons, reasons


def render_report(baseline: dict[str, Any], candidate: dict[str, Any], allowed: bool, reasons: list[str]) -> str:
    lines = [
        "# 版本评测报告",
        "",
        f"- 裁决：{'允许发布' if allowed else '拒绝发布'}",
        f"- baseline 通过率：{baseline['overall_pass_rate']:.1%}",
        f"- candidate 通过率：{candidate['overall_pass_rate']:.1%}",
        f"- candidate 平均成本：{candidate['average_cost']:.4f}",
        f"- candidate P95 延迟：{candidate['p95_latency_ms']:.0f} ms",
        "",
        "## 裁决理由",
    ]
    lines.extend([f"- {reason}" for reason in reasons] or ["- 所有门禁通过"])
    lines.extend(["", "## 逐用例比较", "", "| 用例 | baseline | candidate | 变化 |", "|---|---:|---:|---:|"])
    for case_id, base_case in baseline["cases"].items():
        candidate_rate = candidate["cases"][case_id]["pass_rate"]
        lines.append(f"| {case_id} | {base_case['pass_rate']:.1%} | {candidate_rate:.1%} | {candidate_rate - base_case['pass_rate']:+.1%} |")
    return "\n".join(lines) + "\n"


def main() -> int:
    parser = argparse.ArgumentParser()
    parser.add_argument("--cases", type=Path, default=Path("cases.jsonl"))
    parser.add_argument("--baseline", type=Path, default=Path("baseline.jsonl"))
    parser.add_argument("--candidate", type=Path, default=Path("candidate.jsonl"))
    parser.add_argument("--thresholds", type=Path, default=Path("thresholds.json"))
    parser.add_argument("--output", type=Path, default=Path("artifacts"))
    args = parser.parse_args()

    cases = load_jsonl(args.cases)
    baseline, _ = summarize(cases, load_jsonl(args.baseline))
    candidate, details = summarize(cases, load_jsonl(args.candidate))
    thresholds = json.loads(args.thresholds.read_text(encoding="utf-8"))
    allowed, reasons = decide_release(baseline, candidate, thresholds)

    args.output.mkdir(parents=True, exist_ok=True)
    with (args.output / "details.jsonl").open("w", encoding="utf-8") as handle:
        for row in details:
            handle.write(json.dumps(row, ensure_ascii=False) + "\n")
    payload = {"release": allowed, "reasons": reasons, "baseline": baseline, "candidate": candidate}
    write_json(args.output / "summary.json", payload)
    (args.output / "report.md").write_text(render_report(baseline, candidate, allowed, reasons), encoding="utf-8")
    print("ALLOW" if allowed else "BLOCK")
    return 0 if allowed else 2


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
from __future__ import annotations

import json
from pathlib import Path

    {"id": "cite", "category": "typical", "required_terms": ["来源"], "forbidden_terms": ["编造"], "max_tools": 3, "critical": True},

def write_jsonl(path: Path, rows: list[dict]) -> None:

                "answer": answers[case["id"]],
                "tools": ["search"] if case["id"] != "empty" else [],
                "latency_ms": latency + run * 10,
                "cost": cost,
            })
    return rows


write_jsonl(Path("cases.jsonl"), CASES)
```

## 14. 制造一次真实回归

把 `candidate.jsonl` 中 `cite` 的一条答案改成“不附来源”，再运行：

```bash
python3 eval_gate.py
echo $?
```

预期：输出 `BLOCK`，exit code 为 2。即使其它用例全部通过，关键用例也不能被平均数抵消。

## 15. 接真实 Agent 时只替换哪里

新增一个 runner，把每次真实执行转换成运行记录契约：

```text
case_id / version / run / answer / tools / latency_ms / cost
```

门禁代码不应知道模型厂商、SDK 或 prompt 细节。模型、prompt、工具变了，评测契约保持稳定，才能比较版本。
