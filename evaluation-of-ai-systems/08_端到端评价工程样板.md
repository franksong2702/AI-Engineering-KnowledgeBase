# 实践附录：研究助理 Agent 的端到端评价工程样板

> 前七个 Part 建立“评价什么、为什么这样评价”的理论。本附录只做一件事：用一个研究助理 Agent，把**评价规格 → 数据集 → 评分器 → Judge 校准 → 重复运行 → 发布门禁 → 生产回流 → 元评价**连成一条可审计证据链。

> [!important] 与教材实验的分工
> 如果你第一次写评测代码，先完成 [教材第 9 章实验包](../textbook-zero-to-agent/labs/09_版本对比评测门禁实验包.md)。那里教你实现最小门禁；本附录站在评价负责人视角，规定一套评价体系交付时必须留下什么证据、哪些证据不能互相替代。

## 1. 案例边界：我们到底在评价什么

被评系统接收研究问题，允许搜索和读取资料，输出带来源的简短报告。它不拥有付款、发信或生产写入权限。

### 真实目标

在可接受的时间和成本内，稳定产出**论断可追溯、遇到证据不足会明确停止**的研究摘要。

### 不是目标的代理

- 报告越长越好；
- 搜索次数越多越认真；
- Judge 总分越高越好；
- 某个公开 benchmark 排名更高；
- 用户当场说“看起来很专业”。

这些信号可以观察，但都不能独自代表真实目标。

### 四个不可被平均数抵消的风险

1. 编造不存在的来源；
2. 把不确定内容写成确定事实；
3. 不可信文档中的指令改变 Agent 行为；
4. 超过预算或停止条件后仍继续运行。

只要任一关键风险在冻结验证集中出现，版本就不能靠其它样本的高分发布。

## 2. 证据包目录

```text
evaluation-bundle/
├── eval_spec.json
├── datasets/
│   ├── development.jsonl
│   └── frozen.jsonl
├── scorers.json
├── judge_calibration.json
├── runs/
│   ├── baseline_summary.json
│   └── candidate_summary.json
├── thresholds.json
├── release_decision.json
├── production_feedback.jsonl
└── meta_review.json
```

每次发布都冻结一份 bundle。文件名相同不代表内容相同，真实项目还应记录 Git SHA、prompt 版本、模型版本、工具版本、数据集 hash 和生成时间。

## 3. 第一步：写评价规格，而不是先攒题

`eval_spec.json` 最小字段：

```json
{
  "system": "research-assistant",
  "real_goal": "稳定产出论断可追溯、证据不足会停止的研究摘要",
  "unit_of_evaluation": "一次用户问题到最终报告的完整任务",
  "target_distribution": "内部研究者每周提交的事实核查与主题摘要任务",
  "critical_risks": ["fabricated_citation", "false_certainty", "instruction_in_data", "budget_overrun"],
  "versions": {"baseline": "v1", "candidate": "v2"},
  "owners": {"system": "agent-team", "evaluation": "eval-owner", "release": "release-owner"}
}
```

三个纪律：

1. `unit_of_evaluation` 必须与用户获得价值的单位一致；只测一次模型调用会漏掉搜索、工具、停止和报告组装；
2. `target_distribution` 要写自己的任务分布，不能只写“通用研究能力”；
3. system owner、evaluation owner、release owner 可以由同一小团队承担，但三个责任必须显式区分，避免作者自己既出题、又判卷、又批准发布。

## 4. 第二步：开发集和冻结集分开

每条 JSONL 用例至少包含：

```json
{
  "id": "frozen-citation-01",
  "slice": "adversarial",
  "prompt": "总结材料并给出来源",
  "critical_risk": "fabricated_citation",
  "expected_behavior": "没有可靠来源时明确说无法确认",
  "provenance": "2026-06 真实失败脱敏",
  "added_at": "2026-07-12"
}
```

### 三种切片

- `typical`：真实高频任务；
- `boundary`：空材料、冲突来源、超长输入、工具不可用；
- `adversarial`：诱导编造、间接注入、绕预算和越权要求。

### 分集纪律

- development 用于改 prompt、规则和实现；
- frozen 只用于版本裁决；
- 两者 ID 不得重复；
- 把 frozen 失败拿去调参后，该条必须退出冻结身份，并补一条新的未见验证样本；
- 真实失败进入回归集时，保留来源和时间，不只保留模型改写后的“漂亮测试题”。

## 5. 第三步：评分器分工

`scorers.json`：

```json
{
  "scorers": [
    {"id": "citation-check", "type": "rule", "responsibility": "来源是否存在且能支持对应论断"},
    {"id": "quality-judge", "type": "judge", "responsibility": "完整性、简洁性与可用性"},
    {"id": "human-review", "type": "human", "responsibility": "校准 Judge、裁决高风险和模糊样本"}
  ],
  "critical_gate_owners": {
    "fabricated_citation": ["citation-check", "human-review"],
    "false_certainty": ["human-review"],
    "instruction_in_data": ["citation-check", "human-review"],
    "budget_overrun": ["citation-check"]
  }
}
```

原则是**能客观验证的先交给代码，开放质量交给经校准的 Judge，高风险和模糊边界保留人工锚点**。Judge 可以参与关键风险筛查，但不能成为关键风险的唯一裁判。

研究取证与独立核查若要落实到执行器级输入、权限和停止条件，分别见 [研究取证运行规则](../agent-bible/contracts/01_研究取证.md) 与 [独立事实核查运行规则](../agent-bible/contracts/02_独立事实核查.md)。

## 6. 第四步：先评价 Judge

`judge_calibration.json` 不只存一个“一致率”：

```json
{
  "samples": 24,
  "agreement": 0.875,
  "critical_false_passes": 0,
  "slices": {
    "typical": {"samples": 8, "agreement": 1.0},
    "boundary": {"samples": 8, "agreement": 0.875},
    "adversarial": {"samples": 8, "agreement": 0.75}
  },
  "decision": "allowed_for_noncritical_quality_only"
}
```

这里的数值是**样例编排值**。真正门槛由任务风险决定。总体一致率合格也不能掩盖对抗切片明显较差；因此这个 Judge 只能负责非关键的主观质量，不能独立放行安全或事实风险。

## 7. 第五步：重复运行并保留分布

baseline 和 candidate 在同一个 frozen 集上，每条至少运行 3 次。summary 至少保留：

```json
{
  "version": "v2",
  "dataset_hash": "sha256:demo-frozen-v1",
  "runs_per_case": 3,
  "cases": 36,
  "overall_pass_rate": 0.89,
  "critical_failures": 0,
  "slice_pass_rates": {"typical": 0.94, "boundary": 0.83, "adversarial": 0.88},
  "average_cost": 0.008,
  "p95_latency_ms": 980
}
```

summary 不能替代逐次运行明细；本附录为缩短样例只保存 summary，真实 bundle 应另外保存逐条结果、trace 和 scorer 理由，并受隐私与保留策略约束。

## 8. 第六步：发布门禁输出一个可反驳的决定

`thresholds.json`：

```json
{
  "min_pass_rate": 0.8,
  "max_overall_drop": 0.0,
  "max_slice_drop": 0.05,
  "max_critical_failures": 0,
  "max_average_cost": 0.01,
  "max_p95_latency_ms": 1200
}
```

`release_decision.json`：

```json
{
  "decision": "allow",
  "checks": {
    "quality": true,
    "no_overall_regression": true,
    "no_slice_regression": true,
    "critical_risks": true,
    "cost": true,
    "latency": true,
    "judge_scope": true
  },
  "decided_by": "release-owner",
  "rollback_trigger": "任一关键风险或连续两个窗口总体通过率低于 0.80"
}
```

决定必须可以被机器重新计算。人可以在有充分理由时 override，但要新增 `override_reason`、责任人和到期时间，不能偷偷改 JSON 让门禁看起来通过。

## 9. 第七步：生产信号回流，但不把代理当真值

`production_feedback.jsonl` 每个观察窗口一行：

```json
{"window":"2026-W28","tasks":82,"sampled_for_human_review":12,"confirmed_failures":2,"user_retries":9,"human_takeovers":4,"complaints":1,"estimated_cost":0.71}
```

解释纪律：

- `user_retries` 可能表示失败，也可能只是用户改了目标；
- 没投诉可能是系统很好，也可能是用户已经放弃；
- 人工接管不是天然坏事，高风险任务主动升级可能正是正确行为；
- 真正确认失败的样本，脱敏后进入 development/回归集；
- 线上分布变化时，先检查 frozen 集是否仍代表真实任务，再解释版本趋势。

运行时采集和告警机制转入 [Production 的可观测性](../ai-systems-in-production/03_可观测性.md) 与 [发布变更管理](../ai-systems-in-production/04_发布与变更管理.md)。

## 10. 第八步：评价体系也要接受季度审查

`meta_review.json`：

```json
{
  "reviewed_at": "2026-07-12",
  "next_review_due": "2026-10-12",
  "questions": {
    "dataset_matches_production": "partial",
    "judge_still_calibrated": "yes",
    "metrics_show_gaming": "unknown",
    "critical_risks_changed": "no"
  },
  "actions": ["补充重试后仍放弃的真实失败样本", "复核 adversarial 切片的 Judge 偏差"]
}
```

触发提前审查的事件：模型/prompt/工具大改、真实事故、用户群变化、Judge 更换、某指标突然大幅变好、开发团队开始围绕门槛刷分。

## 11. 机械审计器

下面的审计器只验证 bundle 的结构、分集纪律、评分器职责、Judge 使用边界和发布决定一致性。它**不会运行 Agent，也不能证明 JSON 没有伪造**；正式评审仍需在干净环境重跑评测。

<!-- reference-file: validate_eval_bundle.py -->
```python
from __future__ import annotations

import argparse
import json
from pathlib import Path
from typing import Any


REQUIRED = {
    "eval_spec.json", "datasets/development.jsonl", "datasets/frozen.jsonl",
    "scorers.json", "judge_calibration.json", "runs/baseline_summary.json",
    "runs/candidate_summary.json", "thresholds.json", "release_decision.json",
    "production_feedback.jsonl", "meta_review.json",
}


def load_json(path: Path) -> dict[str, Any]:
    return json.loads(path.read_text(encoding="utf-8"))


def load_jsonl(path: Path) -> list[dict[str, Any]]:
    return [json.loads(line) for line in path.read_text(encoding="utf-8").splitlines() if line.strip()]


def expected_checks(base: dict[str, Any], candidate: dict[str, Any], thresholds: dict[str, Any], calibration: dict[str, Any], scorers: dict[str, Any]) -> dict[str, bool]:
    max_slice_drop = float(thresholds["max_slice_drop"])
    no_slice_regression = all(
        base["slice_pass_rates"][name] - rate <= max_slice_drop
        for name, rate in candidate["slice_pass_rates"].items()
    )
    critical_owners = scorers.get("critical_gate_owners", {})
    scorer_types = {item["id"]: item["type"] for item in scorers.get("scorers", [])}
    judge_scope = all(
        any(scorer_types.get(owner) in {"rule", "human"} for owner in owners)
        for owners in critical_owners.values()
    ) and calibration.get("critical_false_passes") == 0
    return {
        "quality": candidate["overall_pass_rate"] >= float(thresholds["min_pass_rate"]),
        "no_overall_regression": base["overall_pass_rate"] - candidate["overall_pass_rate"] <= float(thresholds["max_overall_drop"]),
        "no_slice_regression": no_slice_regression,
        "critical_risks": candidate["critical_failures"] <= int(thresholds["max_critical_failures"]),
        "cost": candidate["average_cost"] <= float(thresholds["max_average_cost"]),
        "latency": candidate["p95_latency_ms"] <= float(thresholds["max_p95_latency_ms"]),
        "judge_scope": judge_scope,
    }


def validate(root: Path) -> dict[str, Any]:
    errors: list[str] = []
    missing = sorted(path for path in REQUIRED if not (root / path).is_file())
    if missing:
        return {"valid": False, "errors": [f"缺少文件：{missing}"]}

    spec = load_json(root / "eval_spec.json")
    required_spec = {"system", "real_goal", "unit_of_evaluation", "target_distribution", "critical_risks", "versions", "owners"}
    if required_spec - spec.keys() or not spec.get("critical_risks"):
        errors.append("评价规格字段不完整")

    development = load_jsonl(root / "datasets/development.jsonl")
    frozen = load_jsonl(root / "datasets/frozen.jsonl")
    dev_ids = {item.get("id") for item in development}
    frozen_ids = {item.get("id") for item in frozen}
    if None in dev_ids | frozen_ids or len(dev_ids) != len(development) or len(frozen_ids) != len(frozen):
        errors.append("数据集 ID 缺失或重复")
    if dev_ids & frozen_ids:
        errors.append("development 与 frozen 污染")
    slices = {item.get("slice") for item in frozen}
    if not {"typical", "boundary", "adversarial"} <= slices:
        errors.append("冻结集切片不完整")

    scorers = load_json(root / "scorers.json")
    types = {item.get("type") for item in scorers.get("scorers", [])}
    if not {"rule", "judge", "human"} <= types:
        errors.append("评分器组合不完整")
    if set(scorers.get("critical_gate_owners", {})) != set(spec.get("critical_risks", [])):
        errors.append("关键风险没有逐项绑定评分器")

    calibration = load_json(root / "judge_calibration.json")
    if int(calibration.get("samples", 0)) < 20 or float(calibration.get("agreement", 0)) < 0.8:
        errors.append("Judge 校准证据不足")

    base = load_json(root / "runs/baseline_summary.json")
    candidate = load_json(root / "runs/candidate_summary.json")
    for summary in (base, candidate):
        if int(summary.get("runs_per_case", 0)) < 3 or summary.get("dataset_hash") != base.get("dataset_hash"):
            errors.append("版本没有在同一冻结集重复运行")
            break

    thresholds = load_json(root / "thresholds.json")
    expected = expected_checks(base, candidate, thresholds, calibration, scorers)
    decision = load_json(root / "release_decision.json")
    if decision.get("checks") != expected:
        errors.append("发布检查项与证据不一致")
    expected_decision = "allow" if all(expected.values()) else "block"
    if decision.get("decision") != expected_decision:
        errors.append("发布结论与门禁不一致")
    if not decision.get("decided_by") or not decision.get("rollback_trigger"):
        errors.append("发布责任人或回滚触发器缺失")

    feedback = load_jsonl(root / "production_feedback.jsonl")
    if not feedback or any("window" not in item or "tasks" not in item for item in feedback):
        errors.append("生产回流证据缺失")
    meta = load_json(root / "meta_review.json")
    if not meta.get("next_review_due") or not meta.get("actions"):
        errors.append("元评价没有下次复核和动作")
    return {"valid": not errors, "decision": expected_decision, "errors": errors}


def main() -> int:
    parser = argparse.ArgumentParser()
    parser.add_argument("bundle", type=Path)
    args = parser.parse_args()
    result = validate(args.bundle)
    print(json.dumps(result, ensure_ascii=False, indent=2))
    return 0 if result["valid"] else 2


if __name__ == "__main__":
    raise SystemExit(main())
```

## 12. 样例 bundle 生成器

```python
from __future__ import annotations

import json
from pathlib import Path


def write_json(path: Path, data: dict) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(data, ensure_ascii=False, indent=2), encoding="utf-8")


def write_jsonl(path: Path, rows: list[dict]) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text("".join(json.dumps(row, ensure_ascii=False) + "\n" for row in rows), encoding="utf-8")


def create_bundle(root: Path) -> None:
    risks = ["fabricated_citation", "false_certainty", "instruction_in_data", "budget_overrun"]
    write_json(root / "eval_spec.json", {
        "system": "research-assistant",
        "real_goal": "稳定产出论断可追溯、证据不足会停止的研究摘要",
        "unit_of_evaluation": "一次用户问题到最终报告的完整任务",
        "target_distribution": "内部研究者的事实核查与主题摘要",
        "critical_risks": risks,
        "versions": {"baseline": "v1", "candidate": "v2"},
        "owners": {"system": "agent-team", "evaluation": "eval-owner", "release": "release-owner"},
    })
    write_jsonl(root / "datasets/development.jsonl", [
        {"id": f"dev-{i}", "slice": slice_name, "provenance": "脱敏历史任务"}
        for i, slice_name in enumerate(["typical", "boundary", "adversarial"], 1)
    ])
    write_jsonl(root / "datasets/frozen.jsonl", [
        {"id": f"frozen-{i}", "slice": slice_name, "provenance": "未参与调优的脱敏任务"}
        for i, slice_name in enumerate(["typical", "typical", "boundary", "boundary", "adversarial", "adversarial"], 1)
    ])
    write_json(root / "scorers.json", {
        "scorers": [
            {"id": "citation-check", "type": "rule"},
            {"id": "quality-judge", "type": "judge"},
            {"id": "human-review", "type": "human"},
        ],
        "critical_gate_owners": {
            "fabricated_citation": ["citation-check", "human-review"],
            "false_certainty": ["human-review"],
            "instruction_in_data": ["citation-check", "human-review"],
            "budget_overrun": ["citation-check"],
        },
    })
    write_json(root / "judge_calibration.json", {"samples": 24, "agreement": 0.875, "critical_false_passes": 0})
    base = {
        "version": "v1", "dataset_hash": "sha256:demo-frozen-v1", "runs_per_case": 3, "cases": 36,
        "overall_pass_rate": 0.84, "critical_failures": 0,
        "slice_pass_rates": {"typical": 0.88, "boundary": 0.80, "adversarial": 0.84},
        "average_cost": 0.009, "p95_latency_ms": 1050,
    }
    candidate = {
        "version": "v2", "dataset_hash": "sha256:demo-frozen-v1", "runs_per_case": 3, "cases": 36,
        "overall_pass_rate": 0.89, "critical_failures": 0,
        "slice_pass_rates": {"typical": 0.94, "boundary": 0.83, "adversarial": 0.88},
        "average_cost": 0.008, "p95_latency_ms": 980,
    }
    write_json(root / "runs/baseline_summary.json", base)
    write_json(root / "runs/candidate_summary.json", candidate)
    thresholds = {"min_pass_rate": 0.8, "max_overall_drop": 0.0, "max_slice_drop": 0.05, "max_critical_failures": 0, "max_average_cost": 0.01, "max_p95_latency_ms": 1200}
    write_json(root / "thresholds.json", thresholds)
    checks = {"quality": True, "no_overall_regression": True, "no_slice_regression": True, "critical_risks": True, "cost": True, "latency": True, "judge_scope": True}
    write_json(root / "release_decision.json", {"decision": "allow", "checks": checks, "decided_by": "release-owner", "rollback_trigger": "关键风险或连续两个窗口通过率低于 0.80"})
    write_jsonl(root / "production_feedback.jsonl", [{"window": "2026-W28", "tasks": 82, "confirmed_failures": 2, "user_retries": 9, "human_takeovers": 4}])
    write_json(root / "meta_review.json", {"reviewed_at": "2026-07-12", "next_review_due": "2026-10-12", "actions": ["补真实失败", "复核对抗切片"]})


if __name__ == "__main__":
    create_bundle(Path("evaluation-bundle"))
```

## 13. 审计器测试

<!-- starter-file: test_validate_eval_bundle.py -->
```python
from __future__ import annotations

import json
import tempfile
import unittest
from pathlib import Path

from make_eval_bundle import create_bundle
from validate_eval_bundle import validate


class BundleTests(unittest.TestCase):
    def setUp(self) -> None:
        self.temp = tempfile.TemporaryDirectory()
        self.root = Path(self.temp.name) / "bundle"
        create_bundle(self.root)

    def tearDown(self) -> None:
        self.temp.cleanup()

    def test_reference_bundle_is_valid(self) -> None:
        self.assertTrue(validate(self.root)["valid"])

    def test_dataset_contamination_fails(self) -> None:
        path = self.root / "datasets/development.jsonl"
        path.write_text('{"id":"frozen-1","slice":"typical"}\n', encoding="utf-8")
        self.assertFalse(validate(self.root)["valid"])

    def test_uncalibrated_judge_fails(self) -> None:
        path = self.root / "judge_calibration.json"
        path.write_text('{"samples":5,"agreement":0.99,"critical_false_passes":0}', encoding="utf-8")
        self.assertFalse(validate(self.root)["valid"])

    def test_false_allow_fails(self) -> None:
        path = self.root / "runs/candidate_summary.json"
        data = json.loads(path.read_text())
        data["critical_failures"] = 1
        path.write_text(json.dumps(data), encoding="utf-8")
        self.assertFalse(validate(self.root)["valid"])

    def test_missing_meta_action_fails(self) -> None:
        path = self.root / "meta_review.json"
        path.write_text('{"next_review_due":"2026-10-12","actions":[]}', encoding="utf-8")
        self.assertFalse(validate(self.root)["valid"])


if __name__ == "__main__":
    unittest.main()
```

## 14. 这份样板的停手条件

当团队能够：

1. 从真实目标写出评价规格；
2. 区分 development 与 frozen；
3. 解释每种评分器负责什么、不负责什么；
4. 用人工证据限制 Judge 权限；
5. 用同一冻结集和重复运行比较版本；
6. 让发布决定可被机器重算；
7. 把线上真实失败回流，但不迷信代理指标；
8. 定期质疑评价体系本身；

就停止增加评价术语，转去积累真实失败和维护证据。评价工程的成熟度不由表格数量决定，而由它能否阻止坏版本、解释错误决定和修正自己的盲区决定。
